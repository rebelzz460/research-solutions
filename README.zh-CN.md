# 解决方案研究

[English documentation](README.md)

用于开放性问题探索、技术调研、架构对比与方案选型的 agent skill。

[SKILL.md](SKILL.md) 为可安装的英文版，下方提供完整中文翻译。

## 安装

将 `SKILL.md` 放入所用 agent 的 `skills/solution-research/` 目录。

Codex 默认位置为 `~/.codex/skills/solution-research/SKILL.md`。如果已经安装旧名 `research-solutions`，请将其替换为 `solution-research`，避免重复加载。

## 使用

通过 `$solution-research` 提出问题并说明已知约束；支持自动发现 skill 的 agent 也可按适用场景调用。

```markdown
# 解决方案研究 (Solution Research)

按以下四个阶段协助用户调研与选型，不要把用户最初点名的技术路线默认当作唯一解。

## Steps

1. **解析问题与确认边界**
   - 拆解**真实目标**、**硬性约束**（环境、成本、兼容底线）与**可调整假设**（用户顺口提的实现方式）。
   - **确认门控**：若关键约束缺失且会导致检索方向完全分叉，先做最小范围摸底，列出 2-3 个具体分叉点请用户确认，**暂停输出长篇对比**；若上下文足以收敛范围，直接进入下一步。

2. **升维抽象与跨界检索**
   - 剥离非必要限定，将问题还原为“核心需求 + 所需能力”，同步检索宿主原生能力、成熟开源实现、经典模式及跨领域替代路线。
   - **证据与反例**：主动检索每个方向的失败案例、局限或维护踩坑点，用一手来源（文档、源码、实测记录）区分已验证事实与推测，不以热度或新颖性评判优劣。

3. **降维对比与优先级裁剪**
   - 将候选方案放回用户的实际约束中评估，先看解决问题的实际效果，再比成熟度、成本、复杂度与维护风险。
   - **默认选型阶梯**：严格按「复用内置/现有配置 → 引入成熟开源实现 → 轻量组合改造 → 自主开发」逐级筛选；只有前一级无法满足关键需求时才往后降级。

4. **交付决策建议**
   - 仅展示最有价值的候选方案，每项说明：核心优势与主要缺点、适用条件与关键限制、推荐理由及证据依据。
   - 给出明确首选建议，同时保留用户的最终选择权。
```
